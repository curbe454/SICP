(define (eval expr env)
  (cond
    [(self-evaluating? expr) expr]
    [(variable? expr) (lookup-variable-value expr env)]
    [(quoted? expr) (text-of-quotation expr)]
    [(assignment? expr) (eval-assignment expr env)]

                     env)]

      (extend-environment
       (procedure-parameters procedure)

It's the halting problem!

#+begin_src racket :results none
(define (run-forever) (run-forever))

(define (try p)
  (if (halts? p p)
      (run-forever)
      'halted))

To evaluate `(try try)`, if it evaluates to `'halted`, this means `(halts? try try) => false`, `halts?` judges the `try` applied with `try` can be halted. While `halts?` judges the `try` for `try` can halt, the `(halts? try try)` would evaluates to true, and the `(try try)` should run forerver.

If `(try try)` runs forever, this means `halts?` judges the `try` applied with `try` can not halt. While this means `(halts? try try) => false`, it should evaluates to `'halted`.
